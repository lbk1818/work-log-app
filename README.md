# 手机工作日志 App

## 📱 项目简介

一个专为手机端设计的工作日志记录应用，支持三段式结构化记录和 Excel 导出功能。

---

## ✨ 核心功能

- ✅ **三段式记录**：主要工作、思考收获、待解决问题
- ✅ **自动编号**：输入时自动添加 1. 2. 3. 编号
- ✅ **底部导航**：记录/查看/统计三个标签页
- ✅ **数据统计**：今日/本周/本月记录数
- ✅ **导出功能**：支持导出为 Excel 和 TXT 格式
- ✅ **PWA 支持**：可安装到手机主屏幕，离线可用
- ✅ **本地存储**：数据保存在浏览器 localStorage

## 📱 访问方式

### 手机上使用（推荐）

**方法1：浏览器直接访问**
```
http://localhost:8081
```

**方法2：安装到主屏幕（最佳体验）**

#### iPhone (Safari)
1. 用 Safari 打开网址
2. 点击底部“分享”按钮
3. 选择“添加到主屏幕”
4. 点击“添加”

#### Android (Chrome)
1. 用 Chrome 打开网址
2. 点击右上角菜单（三个点）
3. 选择“添加到主屏幕”或“安装应用”
4. 点击“添加”

安装后，应用会像原生 App 一样显示在主屏幕上，无需每次打开浏览器！

## 💾 数据传输到电脑

### 导出 Excel 文件

1. 在手机应用中进入“统计”页面
2. 点击“📊 导出为 Excel”
3. 文件自动下载到手机

### 传输方式

**微信/QQ：**
- 在聊天中发送文件
- 电脑上接收即可

**邮件：**
- 将 Excel 作为附件发送
- 电脑上查收邮件

**云盘：**
- 上传到百度网盘、阿里云盘等
- 电脑上下载

**数据线：**
- USB 连接电脑
- 复制文件到电脑

---

## ⚠️ 重要提示

### 数据备份

⚠️ **数据保存在手机浏览器中，请定期导出备份！**

- 建议每周导出一次 Excel
- 系统会在7天未备份时提醒你
- 清除浏览器数据会导致记录丢失

### 使用场景

✅ **适合：**
- 随时随地用手机记录工作
- 不需要电脑实时查看
- 通过导出文件与电脑共享数据

❌ **不适合：**
- 需要电脑和手机实时同步
- 多人协作编辑

## 📊 使用指南

### 记录工作日志
1. 点击底部"记录"标签
2. 填写三项内容（至少一项）：
   - 1️⃣ 完成主要工作
   - 2️⃣ 主要思考收获
   - 3️⃣ 待解决问题
3. 点击"💾 保存日志"
4. 自动跳转到查看页面

### 查看历史日志
1. 点击底部"查看"标签
2. 浏览所有历史记录
3. 可以删除不需要的日志

### 统计数据
1. 点击底部"统计"标签
2. 查看总记录数、今日/本周/本月记录数

### 导出数据
1. 进入"统计"页面
2. 选择导出格式：
   - 📊 导出为 Excel（推荐）
   - 📄 导出为 TXT
3. 文件自动下载到手机

## 💡 使用技巧

### 自动编号
在文本框中输入内容时，每行会自动添加编号：
```
输入：完成需求分析
自动变成：1. 完成需求分析

按回车后输入：编写技术方案
自动变成：2. 编写技术方案
```

如果手动输入了编号（如 `1. xxx`），会保留你的格式。

### 数据备份
定期导出 Excel 文件进行备份，避免清除浏览器数据时丢失。
